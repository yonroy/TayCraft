Ma trận Jacobian — gradient cho hàm nhiều đầu ra

PHẦN A · TOÁN NỀN
Họ tên: Ngày: Thời gian: ~16 phút
🎯 Nhiệm vụ. Mỗi lớp mạng là hàm vectơ → vectơ; Jacobian là bảng "mỗi đầu ra nhạy thế nào với mỗi đầu vào". Hãy tính 4 đạo hàm riêng, điền ma trận J, tính det J và điền |det J| = diện tích vào ô ✍ trong hình, rồi (Trang 2) xem J biến hình vuông đơn vị thành gì.
0

Cho sẵn hàm vectơ→vectơ

f: ℝ²→ℝ²
f₁ = x² + y  ,  f₂ = x·y  ;  xét tại ( 1, 2 )
Hai đầu ra (f₁, f₂), hai đầu vào (x, y) → Jacobian là ma trận 2×2, vị trí (i, j) = ∂fᵢ/∂xⱼ.
1

Bốn đạo hàm riêng → điền ma trận J

hàng 1 = ∇f₁, hàng 2 = ∇f₂
J 2×2
Hàng 1: ∂f₁/∂x = 2x, ∂f₁/∂y = 1. Hàng 2: ∂f₂/∂x = y, ∂f₂/∂y = x. Thay ( 1, 2 ) vào từng ô.
2

det J = diện tích hình bình hành → điền vào hình

hero · phóng đại cục bộ
det J = 2·1 − 1·2 =
Hai cột của J = ảnh của hai vectơ đơn vị: lam & cam. Điền |det J| = diện tích vùng tô vào ô ✍ trong hình. det J = 0 ⇒ lớp "ép phẳng" thông tin.

Ma trận Jacobian — J biến hình vuông đơn vị thành gì?

PHẦN A · TOÁN NỀN
🎯 Tiếp. Jacobian là xấp xỉ tuyến tính cục bộ: quanh điểm đang xét, một nhiễu nhỏ dx đổi đầu ra ≈ J·dx (đúng phép ma trận×vectơ A8). Hãy đẩy 4 đỉnh của hình vuông đơn vị qua J để thấy cột của J = nơi vectơ đơn vị rơi tới, và diện tích = |det J|.
3

Đẩy 4 đỉnh hình vuông qua J (mỗi đỉnh = J·vectơ, phép A8)

cột = ảnh vectơ đơn vị
J·(1, 0) = ( J₁₁ , J₂₁ ) = ( , ) ← cột 1 của J
J·(0, 1) = ( J₁₂ , J₂₂ ) = ( , ) ← cột 2 của J
J·(1, 1) = ( J₁₁+J₁₂ , J₂₁+J₂₂ ) = ( , ) ← đỉnh xa (cộng 2 cột)
4 đỉnh: (0,0), cột1, đỉnh xa, cột2 → diện tích hình bình hành = |det J| = (khớp Bước 2 ✓)
Vectơ đơn vị (1,0) rơi vào cột 1 của J, (0,1) vào cột 2. Hình vuông diện tích 1 biến thành hình bình hành diện tích |det J| — đó là "hệ số phóng đại diện tích" cục bộ của lớp.

Ma trận J(1, 2)

J
2

1
Hàng 1 = ∇f₁ = (2x, 1); hàng 2 = ∇f₂ = (y, x).
Vì sao: hàng i chỉ quan tâm đầu ra fᵢ; mỗi cột là một biến đầu vào (x trước, y sau). Jacobian = chồng các gradient.
2

det J

det J = 2·1 − 1·2 = 0  →  |det J| = diện tích = 0
Vì sao: hai cột của J căng một hình bình hành, |det J| = diện tích = hệ số phóng đại diện tích cục bộ. Ở điểm này lớp ép phẳng (suy biến). Một nhiễu nhỏ dx đổi đầu ra ≈ J·dx (đúng phép ma trận × vectơ ở A8).
3

J biến hình vuông đơn vị

J·(1,0) = ( 2, 2 )  ·  J·(0,1) = ( 1, 1 )
J·(1,1) = ( 3, 3 )  ·  diện tích = 0
Vì sao: cột 1 = ảnh của (1,0), cột 2 = ảnh của (0,1); hình vuông diện tích 1 → hình bình hành diện tích |det J|. det J = 0 nghĩa 4 đỉnh thẳng hàng (bẹp).
