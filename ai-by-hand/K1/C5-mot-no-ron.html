Một nơ-ron — lời giải & kiểm tra

1

z = w·x + b

w·x = 2 − 1 + 2 = 3  ·  z = 3 + (−1) = 2
2

a = f(z)

ReLU(2) = max(0, 2) = 2  ·  σ(2) = 0.88
4

Đổi đầu vào

x=(0,0,0): z = −1, a = ReLU = 0  ·  x=(2,2,2): z = 2·2−1·2+1·2−1 = 3, a = 3
x=(0,0,0): z = chỉ còn bias = −1 → ReLU cắt về 0 (nơ-ron "tắt"). x=(2,2,2): w·x = 4−2+2 = 4, z = 3.
5

Tự kiểm — ranh giới z = 0

siêu phẳng
z = 2 → dấu dương → σ(z) > 0.5, ReLU bật (a>0)  ·  z = 0: σ(0) = 0.5, ReLU(0) = 0
Vì sao: σ đơn điệu tăng ⇒ σ(z) > 0.5 ⟺ z > 0; ReLU bật ⟺ z > 0. Ranh giới z = w·x + b = 0 là một siêu phẳng — nơ-ron chính là bộ phân loại tuyến tính (B3, B10).
✎ Tự kiểm tra — đáp án
  1. Một nơ-ron = Tích vô hướng w·x + bias b + hàm kích hoạt f → 1 con số.
  2. Bật/tắt tùy → Dấu của z = w·x + b (ranh giới z = 0).
Rút ra. Một nơ-ron = tích vô hướng + bias + kích hoạt → 1 số; ranh giới z = 0 là một siêu phẳng phân loại. Bài C6: đặt nhiều nơ-ron song song trên cùng đầu vào để tạo thành một lớp.
