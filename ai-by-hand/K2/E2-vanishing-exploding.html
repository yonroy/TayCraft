4

Tự kiểm — vì sao lại là hàm mũ?

log
Lấy log biến tích thành tổng: log(rᴸ) = L·log r — số mũ tăng tuyến tính theo độ sâu L. Ví dụ L = 10 (cho log₁₀0.5 = −0.30, log₁₀2 = +0.30):
r=0.5: log₁₀(0.5¹⁰) = 10·(−0.30) = → ‖g‖ ≈ 10đó = 0.001
r=2: log₁₀(2¹⁰) = 10·(+0.30) = → ‖g‖ ≈ 10đó = 1000
r=1: 10·log₁₀(1) = 10·0 =  — ranh giới nằm ở đâu?
Trên trục log, mỗi đường là đường thẳng dốc = log r. r = 1 cho log r = 0 → đường nằm ngang: đúng ranh giới giữa teo và nổ. Lệch r một chút → dốc đổi dấu → sau L lớp lệch cả nghìn lần.
5

Cách chữa

ReLU / init / norm / skip
σ′ ≤ 0.25 gây vanishing → ReLU (đạo hàm 1); init He (E1) giữ r≈1; BatchNorm/LayerNorm (E6/E7) ổn định; residual cho đường tắt gradient; clipping (E9) chặn nổ.

Log: số mũ tuyến tính theo độ sâu

dốc = log r
log(0.5¹⁰) = −3 · log(2¹⁰) = 3 · log(1¹⁰) = 0
Trên trục log, mỗi đường thẳng có dốc = log r: xám (r<1) dốc xuống, lam (r=1) nằm ngang (ranh giới), cam (r>1) dốc lên. Số mũ = L·log r.
✎ Tự kiểm tra — đáp án
  1. Sigmoid sâu vanishing? → σ′ ≤ 0.25 < 1, nhân dồn qua nhiều lớp → teo về 0.
  2. r=1 là ranh giới? → log r = 0 → số mũ L·log r = 0 → rᴸ = 1 (không teo/nổ).
Rút ra. Gradient = tích thừa số = rᴸ; log rᴸ = L·log r tuyến tính theo độ sâu → r<1 teo, r>1 nổ, r=1 ranh giới. Bài E3: một cách kiểm soát độ lớn trọng số — L2 regularization (weight decay).
