Tự kiểm — L2 co nghiệm về đâu?

×1/(1+λ)
Xét một trọng số với loss dữ liệu (w − a)² muốn w = a, cộng phạt λw². Tìm điểm tối ưu: đạo hàm 2(w−a) + 2λw = 0 ⇒ w* = a/(1+λ). Lấy a = 6:
λ = 0.5: w* = 6/(1+0.5) = 6/1.5 =
λ = 2: w* = 6/(1+2) = 6/3 =  ·  hệ số co (λ=0.5) = 1/1.5 =  — về 0 hẳn chưa?
L2 co nghiệm theo hệ số 1/(1+λ): λ lớn → co mạnh, nhưng w* = a/(1+λ) > 0 không bao giờ về 0 hẳn. (Bài E4: L1 mới ép được về 0 → trọng số thưa.)
