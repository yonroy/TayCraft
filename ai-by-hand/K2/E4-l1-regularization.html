L1 regularization — phạt |w| → trọng số thưa (về đúng 0)

PHẦN E · CHUẨN HÓA
Họ tên: Ngày: Thời gian: ~13 phút
🎯 Nhiệm vụ. L1 phạt Σ|w| thay vì Σw². Khác biệt then chốt: L1 kéo w về 0 bằng một lực không đổi λ (theo dấu) → "ghim" các w nhỏ về đúng 0 → mô hình thưa, tự loại đặc trưng nhiễu. Hãy tự tay chạy một bước L1. Phần thưởng: thấy L1 có "vùng chết" ép về 0 hẳn — còn L2 (E3) chỉ co gần 0.
L_tổng = L_data + λ·Σ|wᵢ|  ·  ∂(phạt)/∂wᵢ = λ·sign(wᵢ)  →  w ← w − η(g + λ·sign w)

Tự kiểm — w nhỏ đi đâu?

vùng chết
L1 trừ một lực hằng c = η·λ mỗi bước (theo dấu); L2 trừ lực tỉ lệ 2ηλ·w (nhỏ dần khi w→0). Xét một w rất nhỏ = 0.04, lấy η = 0.1, λ = 0.5:
lực hằng L1: c = η·λ = 0.1·0.5 =
|w| = 0.04 < c → L1 vượt qua 0 → ghim về
cùng w dưới L2: 0.04·(1 − 2ηλ) = 0.04·0.9 =  — cái nào về 0 hẳn?
L1 có vùng chết |w| ≤ c: lực hằng ghim về đúng 0 (soft-threshold). L2 co theo tỉ lệ nên còn 0.036 > 0 — không bao giờ chạm 0. Đó là vì sao chỉ L1 tạo mô hình thưa.
5

Thưa vs mượt — nhìn hình học

L1 ⟂ L2
Vùng phạt L1 là hình thoi có đỉnh nhọn trên trục → nghiệm dễ rơi vào trục (w = 0, thưa). L2 là hình tròn trơn → nghiệm hiếm khi nằm đúng trục. Ghép cả hai = Elastic Net. L1 hợp khi cần chọn đặc trưng tự động.
