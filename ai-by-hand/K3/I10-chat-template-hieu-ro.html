Chat Template — gói hội thoại bằng token đặc biệt (nhìn hình & trả lời)

Họ tên: Ngày: Thời gian: ~13 phút
Vì sao quan trọng. Mô hình chỉ thấy một chuỗi token phẳng. Chat template thêm dấu mốc (vai + ranh giới lượt) để mô hình biết "ai đang nói" và "đến lượt mình trả lời". Sai template → mô hình trả lời lạc / loạn vai.
<|im_start|>role …nội dung… <|im_end|> (lặp mỗi tin nhắn) → kết bằng <|im_start|>assistant
Mã màu xuyên suốt: nội dung tin nhắn (lam) · nhãn vai (role) (cam) · token đặc biệt (mốc) (tím)
💡 Trực giác Như kịch bản sân khấu: mỗi lượt thoại ghi rõ "[VAI]: lời" và dấu hết lượt. Mô hình đọc kịch bản, thấy "[assistant]:" ở cuối còn trống → nó diễn tiếp vai assistant. Token đặc biệt là các dấu mốc đó.

Đếm token đặc biệt cho hội thoại m tin nhắn

start = m+1 · end = m
Nhìn hình: mỗi tin nhắn hoàn chỉnh góp 1 start + 1 end; riêng lượt assistant mở cuối góp thêm 1 start (không end). Đếm tổng mốc tím.

Bài I10

Chat Template — đáp số gọn + cốt lõi

✓

Cụm 1 — giải phẫu tin nhắn

  • Quan sát Mỗi tin nhắn hoàn chỉnh có 2 token đặc biệt (1 start + 1 end).
  • Vì sao Nhãn vai cho mô hình biết đây là chỉ dẫn hệ thống / lời người dùng / lượt mình → xử lý đúng ngữ cảnh.
✓

Cụm 2 — phẳng hóa & mở lượt

  • Quan sát Kết bằng <|im_start|>assistant (mở, chưa có end) → mô hình viết tiếp.
  • Dự đoán Quên nó → mô hình không biết tới lượt mình, dễ nối nhầm vai / im lặng.
✓

Cụm 3 — đếm token đặc biệt

  • Tính start = 3 (m+1) ; end = 2 (m) ; tổng = 5 (2m+1).
  • Vì sao start nhiều hơn end 1 vì lượt assistant cuối mở (có start, chưa end).
  • Vì sao Template dài ăn vào ngân sách token → quan trọng khi hội thoại nhiều lượt / cửa sổ nhỏ.
✓

Cụm 4 — vì sao đúng template

  • Dự đoán Sai kiểu template → lệch phân phối train → trả lời kém, loạn vai.
  • Tóm tắt Gói tin nhắn bằng token đặc biệt đánh dấu vai/lượt; phải khớp định dạng huấn luyện.
Rút ra. Chat template gói tin nhắn bằng token đặc biệt đánh dấu vai / lượt (start/end, m tin nhắn → 2m+1 mốc); phải khớp định dạng huấn luyện. Hết Phần I. Tiếp Phần J (sinh) — Bài J2: VAE reparam + KL.
