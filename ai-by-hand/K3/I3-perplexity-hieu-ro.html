Perplexity — đo độ "bối rối" của mô hình ngôn ngữ (nhìn hình & trả lời)

Họ tên: Ngày: Thời gian: ~13 phút
Vì sao quan trọng. Perplexity (PPL) là chỉ số chuẩn để so sánh mô hình ngôn ngữ: mức "bối rối" trung bình khi đoán token kế. PPL = exp của cross-entropy trung bình → "số lựa chọn hiệu dụng" mô hình phân vân giữa. PPL thấp = tốt (tự tin & đúng).
PPL = exp( −(1/N) Σ ln p(tokenₜ) ) = exp( cross-entropy trung bình )
Mã màu xuyên suốt: p token đúng (lam) · độ bất ngờ −ln p (cam) · PPL (tím)
💡 Trực giác Nếu mô hình chắc chắn đúng (p=1 cho token thật) → bối rối = 1 (không phân vân). Nếu đoán mò giữa V token đều nhau → PPL ≈ V. PPL = "số mặt xúc xắc đều" tương đương với độ bất định của mô hình.

Cụm 1 — Độ bất ngờ

  • Tính −ln p = ( 0.69, 1.39, 0.69 ).
  • Quan sát Token p thấp nhất (0.25) → bất ngờ nhất (−ln = 1.39).
  • Vì sao −ln p: p=1 → 0 (không bất ngờ); p→0 → ∞ (rất bất ngờ) → hợp làm "độ bất ngờ".
✓

Cụm 2 — CE trung bình

  • Tính CE = 0.92 (trung bình 3 giá trị −ln p).
  • Quan sát CE nằm giữa min & max của −ln p.
✓

Cụm 3 — Perplexity

  • Tính PPL = e^CE = 2.51.
  • Quan sát Tương đương phân vân giữa ~2.5 token đều khả năng.
✓

Cụm 4 — Đọc PPL

  • Dự đoán PPL=2.5 < 8 → mô hình A tốt hơn (bối rối ít hơn).
  • Vì sao PPL=1 → luôn gán p=1 cho token đúng (hoàn hảo).
  • Tóm tắt PPL = exp(CE trung bình) = số lựa chọn hiệu dụng; thấp là tốt.
Rút ra. PPL = exp(cross-entropy trung bình) = "số token đều khả năng" mô hình phân vân; thấp là tốt (1 = hoàn hảo, |V| = đoán mò). Bài tiếp (I5): LoRA — tinh chỉnh mô hình lớn rẻ bằng ma trận hạng thấp.
