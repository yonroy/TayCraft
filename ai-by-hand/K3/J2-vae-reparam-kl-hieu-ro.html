VAE — Reparam + KL — hai mẹo cốt lõi của VAE (nhìn hình & trả lời)

Họ tên: Ngày: Thời gian: ~15 phút
Vì sao quan trọng. VAE muốn lấy mẫu z nhưng "lấy mẫu" chặn gradient. Reparam tách ngẫu nhiên ra ε để z khả vi theo μ, σ. KL kéo phân phối ẩn về N(0,1) → vùng ẩn liền mạch, lấy mẫu sinh ảnh mới được.
z = μ + σ·ε, ε ~ N(0,1) · KL = ½ Σ ( μ² + σ² − 1 − ln σ² )
Mã màu xuyên suốt: μ, σ (từ encoder) (lam) · z (mã lấy mẫu) (cam) · ε & vùng N(0,1) (tím)
💡 Trực giác Reparam: thay vì "bốc z ngẫu nhiên" (không đạo hàm được), ta bốc ε cố định rồi dịch & co bằng μ, σ → gradient chảy qua μ, σ như thường. KL: "phạt" nếu mã ẩn lệch khỏi N(0,1) → giữ vùng ẩn gọn, không rỗng chỗ.

Bài J2

VAE — Reparam + KL — đáp số gọn + cốt lõi

✓

Cụm 1 — reparam

  • Tính z = ( 1.5, −0.5 ).
  • Vì sao Bốc z thẳng → bước lấy mẫu chặn gradient (không đạo hàm được) → μ,σ không học được.
  • Quan sát ε = ngẫu nhiên (cố định mỗi lần bốc); μ,σ = học được.
✓

Cụm 2 — KL từng chiều

  • Tính KL = ( 0.5, 0 ) = ( ½μ₁², ½μ₂² ).
  • Quan sát μ = 0 → KL = 0; μ ≠ 0 → bị phạt ½μ².
  • Vì sao (μ,σ)=(0,1) là đúng N(0,1) → không lệch → KL = 0.
✓

Cụm 3 — tổng KL

  • Tính KL = 0.5.
  • Vì sao KL = "lực kéo" mã ẩn về N(0,1); tổng loss = tái tạo + KL.
✓

Cụm 4 — đánh đổi

  • Dự đoán KL quá mạnh (collapse) → tái tạo mờ (bỏ thông tin để về chuẩn).
  • Dự đoán Reparam: cho gradient qua lấy mẫu; KL: kéo ẩn về N(0,1) liền mạch.
  • Vì sao Vùng liền mạch → mọi điểm z lấy mẫu đều giải mã ra mẫu hợp lý (không "lỗ").
Rút ra. VAE = reparam (z = μ+σε, khả vi) + KL (ẩn về N(0,1)); loss = tái tạo + KL, cân bằng bằng β-VAE. Bài tiếp (J3): mô hình sinh đối kháng — GAN.
