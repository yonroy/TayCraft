SARSA — học Q theo hành động THẬT · on-policy

PHẦN K · HỌC TĂNG CƯỜNG
Họ tên: Ngày: ~14 phút · Bài K4 cho sẵn / SARSA Q-learning (max) mục tiêu / δ
🎯 Nhiệm vụ. Cập nhật một ô bảng Q bằng hành động agent THẬT chọn ở s' (ký hiệu a'), không phải max: mục tiêu SARSA → TD error δ → kéo Q một phần α. Rồi đặt cạnh Q-learning để thấy on-policy khác off-policy, khám phá mục tiêu đổi theo a' ra sao, và hiểu vì sao SARSA thận trọng hơn ở "vách đá".
💡 Trực giác. SARSA hỏi: "nếu tôi tiếp tục cư xử như đang cư xử (kể cả thỉnh thoảng đi khám phá), giá trị hành động này là bao nhiêu?" → nó bootstrap bằng a' thật mà agent sẽ làm ở s'. Q-learning (K3) thì lạc quan giả định "từ s' luôn chơi tối ưu (max)". Cùng một luật cập nhật, chỉ khác mục tiêu: a' thật hay a' tốt nhất. Tên SARSA = bộ 5 (S, A, R, S', A').
Cho sẵn — một trải nghiệm (S,A,R,S',A')α = 0.5 · γ = 0.9
Agent ở s làm a: nhận thưởng 1, sang s'. Ô đang sửa Q(s,a) hiện = 2. Ở s', agent thật sự chọn a' (nước khám phá) với Q(s',a') = 3. Hành động tốt nhất ở s' đáng lẽ có maxₐ'Q(s',·) = 4 — nhưng agent không chọn nó.
Luật SARSA: Q(s,a) ← Q(s,a) + α·[ r + γ·Q(s',a') − Q(s,a) ] — dùng a' thật, không phải max. Phần trong [ ] là TD error δ.

Đọc kết quả: Q mới của SARSA thấp hơn Q-learning. SARSA "thừa nhận" agent đôi khi đi nước kém (khám phá) nên đánh giá ô này khiêm tốn hơn. Q-learning lạc quan tin agent luôn chơi tối ưu về sau.
🔬 Khám phá — mục tiêu SARSA đổi theo a' agent chọn
Ở s' có ba hành động với giá trị Q khác nhau. Agent chọn a' nào thì mục tiêu SARSA = r + γ·Q(s',a') lấy đúng ô đó. Điền ba trường hợp:
a' agent chọna' kém (Q=1)a' thật (Q=3)a' tốt nhất (Q=4)
mục tiêu SARSA
→ Mục tiêu đi theo hành động thật của agent = on-policy. Chỉ khi agent tình cờ chọn a' tốt nhất, mục tiêu SARSA mới trùng Q-learning. Đây chính là điều làm SARSA "học cả phần khám phá".
Vách đá — vì sao SARSA đi vòng an toànon-policy tính cả rủi ro khám phá
Đường cam (Q-learning) đi sát mép vách — ngắn nhất nếu không lỡ chân. Đường lam (SARSA) đi vòng xa mép. Vì SARSA tính cả nước khám phá ngẫu nhiên (đôi khi bước nhầm xuống vực −100), nó né mép → an toàn hơn dù dài hơn.
🔮 Dự đoán. Nếu tắt hẳn khám phá (không bao giờ đi sai), hai đường sẽ giống hay khác nhau? Vì sao?
🔎 Tự kiểm — bất biến: SARSA ≤ Q-learning (vì a' thật ≤ max)
Với mọi bộ số, mục tiêu SARSA không bao giờ vượt Q-learning. Kiểm bằng chính bộ số đề:
Q-learn − SARSA = γ·(max − a') = 0.9·(4 − 3) = ≥ 0
→ Hiệu luôn ≥ 0 vì a' thật ≤ max (max là lớn nhất). Bằng 0 đúng khi agent chọn a' tốt nhất. Đó là lý do SARSA cho ước lượng thận trọng (≤) — nền tảng cho hành vi an toàn ở vách đá.

SARSA vs Q-learning — đáp án hai cách
SARSA (a' thật, Q=3)
mục tiêu = 1+0.9·3 = 3.7
Q ← 2+0.5·(3.7−2) = 2.85

mục tiêu = 1+0.9·4 = 4.6

on-policy vs off-policy. SARSA đánh giá chính sách đang chạy (gồm khám phá) → mục tiêu bám a' thật → on-policy, thận trọng. Q-learning đánh giá chính sách tối ưu bất kể agent làm gì → dùng max → off-policy, lạc quan. Cùng luật kéo-một-phần-α, khác nhau đúng một chỗ: mục tiêu.
🔬 Mục tiêu SARSA theo a' — đáp án
mục tiêu = r + γ·Q(s',a'): a' kém → 1.9  ·  a' thật → 3.7  ·  a' tốt nhất → 4.6
Kết luận. Mục tiêu chạy theo hành động thật của agent (on-policy). Chỉ khi a' = tốt nhất thì SARSA mới bằng Q-learning. Vì agent còn khám phá (đôi lúc chọn a' kém), mục tiêu SARSA trung bình thấp hơn → học chính sách an toàn.
🔎 Bất biến SARSA ≤ Q-learning — đáp án
Q-learn − SARSA = 0.9·(4 − 3) = 0.9 ≥ 0
Hiệu luôn ≥ 0 (a' thật ≤ max). Dấu "=" xảy ra khi agent chọn đúng hành động tốt nhất → khi đó SARSA ≡ Q-learning. Nói cách khác: giảm khám phá → SARSA tiến về Q-learning.
Sai lầm thường gặp
  • Dùng max thay a' thật: đó là Q-learning, không phải SARSA. SARSA lấy đúng Q(s',a') của hành động agent sẽ làm.
  • Quên γ: lấy r + Q(s',a') thay vì r + γ·Q(s',a') → mục tiêu phồng.
  • Nhầm dấu δ: δ = mục tiêu − Q (không phải Q − mục tiêu).
  • Nhảy hẳn (α=1): Q ← mục tiêu, bỏ hết kinh nghiệm cũ → dao động theo nhiễu.
  • Tưởng SARSA luôn kém Q-learning: ở môi trường rủi ro (vách đá), chính sách an toàn của SARSA được điểm thực tế cao hơn.
Rút ra. SARSA: Q ← Q + α·(r + γ·Q(s',a') − Q) với a' thật → on-policy: học giá trị chính sách đang chạy (gồm khám phá) → thận trọng, an toàn ở môi trường rủi ro; mục tiêu SARSA ≤ Q-learning, bằng nhau khi hết khám phá.
