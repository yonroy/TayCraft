Triplet loss — neo · dương · âm + lề (nhìn hình & trả lời)

Họ tên: Ngày: Thời gian: ~13 phút
Vì sao quan trọng. Cho nhận diện khuôn mặt, truy hồi ảnh: cần "cùng người gần, khác người xa". Triplet loss định nghĩa trực tiếp yêu cầu đó với một lề (margin) → embedding có cấu trúc khoảng cách rõ ràng (FaceNet).
L = max( 0, d(a,p) − d(a,n) + margin ) (= 0 khi d(a,n) ≥ d(a,p) + margin)
Mã màu xuyên suốt: neo a (lam) · dương p (cùng lớp) (tím) · âm n (khác lớp) (cam)
💡 Trực giác Kéo positive (cùng lớp) lại gần neo và đẩy negative (khác lớp) ra xa, nhưng chỉ tới khi cách nhau đủ một lề — vượt lề rồi thì thôi (loss = 0), khỏi tốn sức. Lề tạo "khoảng đệm an toàn" giữa các lớp.

Bài M3

Triplet loss — đáp số gọn + cốt lõi

✓

Cụm 1 — biểu thức

  • Tính d(a,p) − d(a,n) + margin = 2.
  • Vì sao > 0 → âm gần hơn mức "dương + lề" → vi phạm → phải phạt.
✓

Cụm 2 — loss

  • Tính L = max(0, 2) = 2 (vi phạm → phạt).
  • Quan sát L > 0 → bộ ba khó → kéo/đẩy mạnh khi cập nhật.
✓

Cụm 3 — ca đã thỏa

  • Tính 2 − 4 + 1 = −1 → L = max(0, −1) = 0.
  • Vì sao Đã đủ lề → 0 gradient → khỏi tốn sức chỉnh thêm.
✓

Cụm 4 — hard mining

  • Dự đoán L = 0 khi d(a,n) ≥ d(a,p) + margin (cách đủ lề).
  • Tóm tắt Ép cùng-lớp gần, khác-lớp xa một lề; chọn hard negative để học hiệu quả.
